# Contributing

Pull requests are welcome on [tomaj/nette-auto-variable-template](https://github.com/tomaj/nette-auto-variable-template). [CONTRIBUTING.md](https://github.com/tomaj/nette-auto-variable-template/blob/master/CONTRIBUTING.md) is the project policy; this page matches it. Participation follows the [code of conduct](https://github.com/tomaj/nette-auto-variable-template/blob/master/CODE_OF_CONDUCT.md). Security vulnerabilities are reported in private, see [Security](/guide/security).

## Changes we can merge

- Follow [PER Coding Style](https://www.php-fig.org/per/coding-style/). `composer phpcs` checks `src` and `tests`.
- Add tests for every behaviour change.
- Document behaviour changes in `README.md`, these pages and `CHANGELOG.md`.
- [Semantic Versioning](https://semver.org/): breaking changes wait for the next major version.
- One pull request per change, from a feature branch.

## Checks

```bash
composer install
composer check      # code style, PHPStan, Rector, tests
composer coverage   # HTML and Clover coverage in build/ (Xdebug or PCOV)
composer infection  # mutation testing
```

CI runs the tests on PHP 8.4 (also with the lowest dependencies), 8.5 and 8.6, plus a nightly PHP 8.7 that may fail. PHP 8.6 also checks the statement coverage and runs Infection.

## Examples

Every example in [`examples/`](https://github.com/tomaj/nette-auto-variable-template/tree/master/examples) is a small project with a `run.php` and an `expected-output.txt`, included in the [example pages](/examples/). Run one the way CI does:

```bash
examples/ci/run.sh hello-world
```

It installs the example against your checkout (a Composer path repository), runs `run.php` and diffs the output with `expected-output.txt`. A change that changes an example's output updates `expected-output.txt` in the same pull request. A new example also needs its name in `.github/workflows/examples.yml` and a page in `docs/examples/` and `docs/sk/examples/`.

## Documentation

The site is built with [VitePress](https://vitepress.dev/) from `docs/`:

```bash
cd docs
npm ci
npm run docs:dev    # local preview
npm run docs:links  # build and check every link
npm run check:svg   # check every SVG in public/
```

- Every `php` code block in these pages, `README.md` and `UPGRADE-4.0.md` is run by `tests/DocsSnippetsTest.php` in the PHPUnit suite, every `neon` block is parsed and every `latte` block compiled. A block marked with `<!-- snippet: skip -->` is not checked; an `html` block marked with `<!-- snippet: output -->` must match the output of the PHP block before it.
- The Slovak pages in `docs/sk/` have the same paths as the English ones and the same code blocks; when you change an English page, update its Slovak twin too. `python3 scripts/check-locales.py` (run in CI) fails when a page has no twin or the code blocks differ.
- Code from the examples is included with `<<< @/../examples/<name>/<file>`, never copied.
- The hero illustration, the feature icons and the diagrams are generated by `python3 scripts/illustrations.py` (light and dark variants). After a logo change, `npm run images` regenerates the favicons and the social card `public/og.png` (needs Chrome; set `CHROME_PATH`).
